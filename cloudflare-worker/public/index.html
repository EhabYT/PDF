Deployment notice

OmniFix Private Scanner is not running here

This Cloudflare Worker only serves a static notice. It is not the OmniFix application. OmniFix is a full-stack private document scanner with a Python FastAPI backend, background worker, OCR, SQLite database and private local file storage. Those components cannot run as a normal Cloudflare Worker.

To run the real application:

  • Deploy the repository with Docker Compose on your own server or PC.
  • Expose it privately using Cloudflare Tunnel and protect it with Cloudflare Access.
  • Disconnect the failing Workers Builds integration if you do not want this notice page deployed.
docker compose -f docker-compose.yml \
  -f deployment/cloudflare/docker-compose.cloudflare.yml up -d --build

docker compose exec api python -m app.bootstrap --username owner
